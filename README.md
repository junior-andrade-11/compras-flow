# 📋 ComprasFlow — Controle de Retiradas e Entregas

Aplicativo web criado para controlar entregas e retiradas de materiais no processo de Compras.

> ⚠️ **Status:** projeto descontinuado no uso interno. Foi a base que evoluiu para o módulo **Quadro** da Central de Compras.

## 🎯 Para que serve

Substitui o controle manual realizado em planilhas a partir de cards do Trello, organizando pedidos, prazos, prioridades e status.

## ⚙️ Funcionalidades

- Tabela de pedidos pendentes e concluídos
- Prioridade editável
- Concluir e reabrir pedidos
- Indicador de atraso
- Calendário por data de vencimento
- Painel de pendências
- Tema claro/escuro
- Cores de prioridade personalizáveis
- Salvamento com `localStorage`
- Sincronização opcional com Trello via API

## 🛠️ Tecnologias

`HTML` `CSS` `JavaScript` `localStorage` `Trello API`
